## 这个应用是干什么的

**一句话**：同时用好几个 AI 编程工具的人，不用来回切窗口，看一眼 MacBook 顶部的刘海，就知道哪个 AI 还在干活、哪个已经干完，以及每家的订阅额度和余额还剩多少。

**解决的问题**：Codex、Claude Code、Grok、Cline、Pi 这些工具经常要跑几分钟到几十分钟。人在等待时切去做别的事，就不知道它们什么时候跑完；额度也分散在各家网站上，经常用着用着就被限流。

**你会看到什么**：

| 状态 | 刘海上显示什么 |
|---|---|
| 收起（平时） | 刘海左侧是一滴液态融球：几个任务在跑就有几颗小球绕着转，完成变绿、出错变红、空闲变灰；右侧是各家额度的小圆环和剩余百分比 |
| 展开（鼠标移上去） | 各家额度的详细数字与重置时间、正在运行的项目、打开对应工具的按钮 |
| 任务完成时 | 刘海合拢成黑色徽章，画出对勾，下方写明是谁完成的，例如 `Claude Code · claude-opus-5-5`、`Pi · Cline Pass · glm-5.3-flash` |

**支持的来源**：

- **任务状态**（读取本机会话记录，不联网）：Codex、Claude Code、Grok、Cline、Pi 命令行、PI-Desktop。
- **额度与余额**（只读查询）：Codex API（Sub2API 中转站）、Codex 官方账号、Cline Pass、Claude 订阅、SuperGrok。

**它不做什么**：

- 不发送任何模型请求，不代替你调用 AI。
- 不保存、不上传对话内容，只记录事件类型、时间、项目目录名和模型名。
- 复用其他工具的登录时只读不写，不会让 Claude Code、Grok 掉登录。

**形态**：常驻菜单栏、不占 Dock 的原生 macOS 应用（SwiftUI + AppKit），无第三方运行时依赖，MIT 开源。需要 macOS 14 以上；没有刘海的 Mac 显示为顶部胶囊。

安装与使用见 [README](../README.md)，接口与实现细节见 [工作原理](how-it-works.md)。

## 已知问题与风险

- **非公开接口**：Claude、Grok、Cline 的额度接口是各家官网或 CLI 自用的接口，可能随时变化；失败时保留旧值并提示。
- **未签名与未公证**：没有 Apple Developer ID。别人首次打开需右键“打开”；读取 Claude Code 钥匙串项的回退路径在每次重新编译后仍需授权（主路径走 `security` 工具，不受影响）。
- **旧钥匙串条目残留**：旧版本的 `cline-oauth` 钥匙串条目因授权绑定旧二进制无法自动导入或删除；不影响使用（Cline 已改用 API Key），可在“钥匙串访问”中手动删除。
- **任务监听依赖本地文件格式**：各工具升级改格式后可能识别不到，需要跟进；只识别明确的结束事件，不判断“等待审批”。

## 开发备忘

- 构建与运行：`bash scripts/build-app.sh && open "dist/Sea Coffee.app"`
- 检查：`swift run IslandChecks`（43 项）、`bash scripts/check-account-isolation.sh`、`bash scripts/check-credentials.sh`
- 目录：`Sources/IslandCore` 放与界面无关、可测试的逻辑（各家协议解析、会话状态机、凭据文件、PI-Desktop 数据库读取）；`Sources/SeaCoffee` 放界面与账号接入。
- 几个关键决定：
  - **零第三方依赖**：动效、加载、SVG 图标、SQLite 读取均用系统框架实现。
  - **复用其他工具的登录只读不写**：从不刷新 Claude、Grok 的令牌，避免让原工具掉登录。
  - **未知就显示未知**：不把缺失数据显示成 0% 或 100%。
  - **隐私**：只保留事件类型、时间、项目目录名与模型名，不保存对话内容。
